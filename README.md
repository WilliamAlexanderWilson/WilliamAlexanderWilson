## Featured project

### Daily Levels

Daily Levels is a market research dashboard I continue to build for BTC, ETH, and SPY. It combines live market data, calculated levels, global session tracking, historical backtests, prospective evidence gates, and paper trade planning.

The main goal is to keep measured data, modeling, and personal decisions separate. The dashboard records sample sizes and limitations, preserves negative results, and avoids presenting a watch area as a guaranteed signal.
